# Socratic Design System — Material Design 3 Expressive (M3X)

## Design Principles
- Strict CSS Grid layout exclusively (NO Flexbox)
- Material Design 3 Expressive shape tokens (24px asymmetry, pill buttons, rounded corners)
- Spring motion physics with 60 FPS hardware acceleration
- High contrast, dark and light mode dynamic color schemes
- Ergonomic touch targets (>= 48px) for Kiosk, POS, Tablet and Mobile
