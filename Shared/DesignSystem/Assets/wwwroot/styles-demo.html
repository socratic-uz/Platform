Косяк 1: Grid Track Blowout (голый 1fr)

Без minmax(0, 1fr) и min-width: 0 длинное неразрывное слово распирает экран

Правильная колонка (minmax(0, 1fr))

min-width: 0 предотвращает распирание ячейки

rule: minmax(0, 1fr) + min-width: 0

Косяк 2: Срезка теней (overflow: hidden)

Слепой overflow: hidden обрезает мягкие тени M3 Expressive и меню

Карточка с тенью без overflow-ловушки

Тени плавно рассеиваются за пределами границ карточки

rule: overflow: clip / visible

Косяк 3: Мобильное перекрытие нижним баром

Фиксированная навигация (72px) перекрывает нижний контент без клиренса

Нижний клиренс контента (.app-main)

padding-bottom: 72px гарантирует видимость последней кнопки

rule: padding-bottom: calc(72px + env(safe-area-inset-bottom))

Косяк 4: Нарушение тач-зон POS и киосков

Интерактивные элементы менее 44×44px приводят к ложным кликам гостей

check_circle Стандарт 48×48px touch_app
rule: min-height: 48px; min-width: 48px;

Косяк 5: Жесткая минимальная ширина в autofit

minmax(320px, 1fr) на экране 320px с отступами вызывает горизонтальный скролл

minmax(min(100%, 300px), 1fr)

Безопасно сжимается до 100% ширины мобильного экрана

rule: minmax(min(100%, 300px), 1fr)
