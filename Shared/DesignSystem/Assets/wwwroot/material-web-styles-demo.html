bug_report Аудит косяков верстки и дефектов M3 (CSS Defect Audit)

Наглядное визуальное сравнение типичных косяков верстки и их канонических решений в экосистеме Socratic.

error_outline
Косяк 1: Grid Track Blowout (голый 1fr)
Без minmax(0, 1fr) длинное слово распирает контейнер

В CSS Grid гибкая колонка по умолчанию имеет min-width: auto. При длинном слове колонка расширяется до длины слова, ломая адаптивную сетку:

Тест усечения (КотлетаBlackAngusМраморнаяГовядинаФирменныйСоусБезПробелов):
КотлетаBlackAngusМраморнаяГовядинаФирменныйСоусБезПробелов
Решение: minmax(0, 1fr) + min-width: 0
layers_clear
Косяк 2: Обрезка теней и меню (overflow: hidden)
Слепой overflow: hidden срезает тень M3 Expressive

Если на карточку с хроматической тенью или меню повесить overflow: hidden, тень будет срезана ровно по границе:

auto_awesome
Карточка с хроматической тенью
overflow: visible / clip сохраняет мягкое свечение
Решение: overflow: clip / visible
touch_app
Косяк 3: Мелкие тач-таргеты (WCAG & POS)
Кнопки меньше 44×44px приводят к ошибкам нажатий

Стандарт WCAG 2.1 AA требует минимум 44×44px, а стандарт сенсорных киосков Socratic POS — 48×48px:

check_circle Канонический размер (48px) verified
Решение: min-height: 48px; min-width: 48px;
warning
Косяк 4: Переполнение полей ввода и ошибок
Длинное сообщение валидации не должно сдвигать сетку

Проверка поведения поля при экстремальном тексте ошибки:

Решение: grid-template-rows: auto auto minmax(0, 1fr)
