# Реестр разрешенных тегов экосистемы Socratic

В данном документе зафиксирован официальный стандарт разрешенных тегов в разметке Blazor (`*.razor`) и CSS-архитектуре экосистемы Socratic.

> **Архитектурный закон соответствия**:
> - Если нативный HTML5-тег имеет официальную замену в Google Material Design 3 (`Material.Web`), нативный тег **запрещен** к использованию в разметке.
> - Нативные HTML5-теги используются **только** для семантической структуры, разметки текста, таблиц и контейнеров, не имеющих аналогов в Material Design.

---

## 1. Ориентиры документа и макросетки (Document Landmarks & Layouts)

Теги верхнего уровня DOM-дерева, формирующие несущий каркас страницы и макросетку приложения.

| Тег | Назначение |
| :--- | :--- |
| `<body>` | Корневой контейнер экрана с единой универсальной 3-колоночной макросеткой CSS Grid. |
| `<header>` | Глобальная верхняя панель приложения (`body > header`) или внутренняя шапка секции/статьи. |
| `<aside>` | Левая навигационная область (`body > aside:has(~ main)`), правая панель (`body > main ~ aside`) или боковой виджет. |
| `<main>` | Основная рабочая область экрана с контентом страницы (`body > main`). |
| `<footer>` | Глобальный подвал экосистемы (`body > footer`) или внутренний подвал статьи/секции. |
| `<nav>` | Навигационный рельс на десктопе, нижний бар на мобильных устройствах или блок ссылок. |

---

## 2. Структурные разделы и смысловые контейнеры (Sectioning & Containers)

Семантические блоки для группировки контента и построения виджетов.

| Тег | Назначение |
| :--- | :--- |
| `<section>` | Самостоятельный тематический раздел страницы или корень композитного виджета (`<section cart>`). |
| `<article>` | Автономная смысловая единица (статья, запись блога, комментарий). Чистый тег без рамок карточки. |
| `<hgroup>` | Контейнер для группировки заголовка (`<h1>..<h6>`) и его подзаголовка / бейджа. |
| `<figure>` | Контейнер для самостоятельного визуального контента (иллюстрация, схема, фото, аватар). |
| `<figcaption>` | Поясняющая текстовая подпись к содержимому тега `<figure>`. |
| `<div>` | Нейтральный контейнер общего назначения (используется строго при отсутствии семантического аналога). |

---

## 3. Интерактивные блоки и раскрывающиеся списки (Disclosures & Details)

Интерактивные нативные элементы группировки и раскрытия данных, не требующие JavaScript.

| Тег | Назначение |
| :--- | :--- |
| `<details>` | Раскрывающийся блок / аккордеон с переключаемым состоянием отображения. |
| `<summary>` | Заголовок и интерактивный триггер для раскрытия содержимого тега `<details>`. |

---

## 4. Списки и структурированные перечисления (Lists & Collections)

Элементы для отображения последовательностей, меню и пар ключ-значение.

| Тег | Назначение |
| :--- | :--- |
| `<ul>` | Неупорядоченный список элементов. |
| `<ol>` | Упорядоченный (нумерованный) список элементов. |
| `<li>` | Элемент упорядоченного или неупорядоченного списка. |
| `<dl>` | Список описаний / определений (структура ключ-значение). |
| `<dt>` | Термин или ключ в списке описаний `<dl>`. |
| `<dd>` | Описание, определение или значение для предшествующего термина `<dt>`. |
| `<menu>` | Горизонтальная или вертикальная панель командных элементов / кнопок. |

---

## 5. Табличные данные (Tabular Data)

Отображение двумерных данных, матриц цен, отчетов и аналитики.

| Тег | Назначение |
| :--- | :--- |
| `<table>` | Контейнер таблицы данных. |
| `<caption>` | Название / заголовок таблицы. |
| `<thead>` | Группа строк заголовков столбцов таблицы. |
| `<tbody>` | Основное тело таблицы с информационными строками. |
| `<tfoot>` | Строка или группа строк итогов / сводных данных таблицы. |
| `<tr>` | Строка ячеек таблицы. |
| `<th>` | Ячейка заголовка (столбца или строки). |
| `<td>` | Стандартная ячейка данных таблицы. |

---

## 6. Типографика, цитаты и текст (Typography & Phrasing)

Элементы оформления текста, заголовков и смыслового выделения.

| Тег | Назначение |
| :--- | :--- |
| `<h1>` .. `<h6>` | Заголовки уровней 1–6 в соответствии с типографической шкалой M3. |
| `<p>` | Текстовый абзац. |
| `<a>` | Гиперссылка для перехода по страницам и внешним ресурсам. |
| `<blockquote>` | Блок развернутой цитаты с акцентной полосой слева. |
| `<q>` | Краткая встроенная цитата внутри строки. |
| `<cite>` | Указание источника цитаты, автора или названия произведения. |
| `<code>` | Фрагмент компьютерного кода или термина в моноширинном шрифте. |
| `<pre>` | Блок предварительно отформатированного текста / кода с сохранением пробелов. |
| `<kbd>` | Обозначение клавиши клавиатуры или комбинации клавиш. |
| `<samp>` | Пример вывода компьютерной программы или терминала. |
| `<strong>` | Важный текст с полужирным начертанием. |
| `<em>` | Текст с логическим ударением (курсив). |
| `<mark>` | Выделенный / подсвеченный текст (например, совпадение при поиске). |
| `<small>` | Мелкий пояснительный текст (дисклеймер, копирайт). |
| `<time>` | Машиночитаемая и человекочитаемая дата или время. |
| `<abbr>` | Аббревиатура или акроним с расшифровкой в атрибуте `title`. |
| `<sub>` | Нижний индекс (для формул и индексов). |
| `<sup>` | Верхний индекс (для сносок и степеней). |
| `<hr>` | Семантический тематический разделитель между параграфами. |

## 7. Компоненты Material Design 3 (`Material.Web`)

Официальные компоненты пользовательского интерфейса Google Material Web (`<md-*>`).

| Тег | Назначение |
| :--- | :--- |
| `<md-filled-button>` | Главная акцентная кнопка действия с заливкой. |
| `<md-outlined-button>` | Вторичная контурная кнопка действия. |
| `<md-text-button>` | Текстовая кнопка без рамки для низкоприоритетных действий. |
| `<md-elevated-button>` | Приподнятая кнопка с тенью для контраста на ярких фонах. |
| `<md-filled-tonal-button>` | Тональная кнопка со средним визуальным весом. |
| `<md-icon-button>` | Кнопка-иконка без заливки для панелей инструментов. |
| `<md-filled-icon-button>` | Залитая акцентная кнопка-иконка. |
| `<md-outlined-icon-button>` | Контурная кнопка-иконка. |
| `<md-fab>` | Плавающая кнопка действия (Floating Action Button). |
| `<md-branded-fab>` | Брендированная плавающая кнопка действия. |
| `<md-outlined-text-field>` | Контурное поле ввода текста / чисел. |
| `<md-filled-text-field>` | Залитое поле ввода текста. |
| `<md-outlined-select>` | Выпадающий список выбора из вариантов (контурный). |
| `<md-filled-select>` | Выпадающий список выбора из вариантов (залитый). |
| `<md-select-option>` | Элемент выбора внутри `<md-*-select>`. |
| `<md-checkbox>` | Флажок множественного выбора. |
| `<md-radio>` | Радиокнопка одиночного выбора из группы. |
| `<md-switch>` | Переключатель состояния (вкл / выкл). |
| `<md-slider>` | Слайдер выбора числового значения из диапазона. |
| `<md-circular-progress>` | Круговой индикатор загрузки / ожидания. |
| `<md-linear-progress>` | Линейный индикатор прогресса операции. |
| `<md-dialog>` | Модальное диалоговое окно или всплывающая шторка. |
| `<md-elevated-card>` | Приподнятая карточка с тенью. |
| `<md-outlined-card>` | Контурная карточка с границей. |
| `<md-filled-card>` | Залитая карточка для фонового контента. |
| `<md-tabs>` | Контейнер горизонтальных вкладок переключения видов. |
| `<md-primary-tab>` | Основная вкладка верхнего уровня. |
| `<md-secondary-tab>` | Вторичная вкладка подраздела. |
| `<md-chip-set>` | Набор интерактивных чипов/тегов. |
| `<md-filter-chip>` | Чип выбора и фильтрации с отметкой активности. |
| `<md-assist-chip>` | Вспомогательный чип быстрого действия или подсказки. |
| `<md-input-chip>` | Входной чип (например, введенный тег или контакт). |
| `<md-suggestion-chip>` | Чип рекомендованного варианта или ответа. |
| `<md-badge>` | Бейдж со счетчиком или индикатором уведомлений. |
| `<md-divider>` | Разделительная линия между элементами списков и секций. |
| `<md-list>` | Список элементов Material Design. |
| `<md-list-item>` | Строка/элемент списка со слотами иконки и текста. |
| `<md-menu>` | Всплывающее меню контекстных действий. |
| `<md-menu-item>` | Пункт контекстного всплывающего меню. |
| `<md-icon>` | Контейнер вариативного шрифта Material Symbols. |
| `<md-ripple>` | Анимация интерактивного отклика на нажатие (Ripple). |
