# Страница ошибки приложения (`Error.razor`)

## 1. Назначение и бизнес-возможности
- **Целевая роль**: Пользователи платформы, системные инженеры и разработчики, столкнувшиеся с непредвиденным исключением или системным сбоем в процессе обработки запроса.
- **Назначение экрана**: Системная страница аварийного завершения операции (Error Handler Page) Blazor Web App, отображающая сквозной идентификатор трассировки (`RequestId`) для локализации инцидента и регламентное предупреждение о конфигурации сред исполнения.
- **Бизнес-возможности (по коду)**:
  - Визуальное уведомление пользователя о возникновении серверной ошибки.
  - Фиксация и отображение уникального идентификатора запроса (`RequestId`) на базе OpenTelemetry `Activity.Current?.Id` или `HttpContext.TraceIdentifier` для сквозного аудита логов в телеметрии (Jaeger, Grafana, Seq).
  - Справочная секция для разработчиков о правилах переключения в режим разработки (`ASPNETCORE_ENVIRONMENT = Development`) и предупреждение о недопустимости включения детального вывода исключений в production-окружении для предотвращения утечки конфиденциальных данных.

## 2. Паспорт маршрута и доступа
- **Маршруты**: `/Error`
- **Доступ**: Публичный (системный маршрут страницы ошибок ASP.NET Core Middleware).
- **SEO / Метаданные**:
  - Заголовок: `<PageTitle>Error</PageTitle>`.

## 3. Лейаут, ориентиры и панели (`aside.md`)
- **Корневой атрибут**: отсутствует (чистый тег `<main>`).
- **Ориентиры**:
  - `<main>`: основной ориентир с информационными блоками ошибки.
  - `<Aside />` и `<AsideOutlet />`: структурные точки монтирования боковой панели лейаута платформы.
  - `<Header>`, `<Footer>`, `<Fab>`: отсутствуют в разметке страницы.
- **Панели и диалоги**:
  - Модальные шторки и диалоги отсутствуют.

## 4. Виджеты, компоненты и стили
- **Стили страницы**: Специализированный `pages/error.css` не используется; разметка оформления наследуется из общих фундаментов дизайн-системы (`foundations/landmarks.css`, `foundations/typography.css`).
- **Виджеты и ключевые компоненты**:
  - `<Color />`: инициализатор цветовой схемы и системных токенов темы оформления.
  - `<Aside />`, `<AsideOutlet />`: плейсхолдеры ориентира боковой панели.
  - Базовые HTML5-элементы: `<h1>`, `<h2>`, `<h3>`, `<p>`, `<strong>`, `<code>`.

## 5. Поведение, UseCases и состояния (IX)
- **Инжектируемые сервисы / UseCases**:
  - `[CascadingParameter] HttpContext? HttpContext`: каскадный HTTP-контекст сервера для извлечения `TraceIdentifier`.
  - `[Inject] IStringLocalizer L`: сервис локализации интерфейса.
- **Ключевые сценарии и состояния**:
  - **Инициализация (`OnInitialized`)**: считывание сквозного `Activity.Current?.Id` из диагностической активности, либо fallback на `HttpContext?.TraceIdentifier`.
  - **Состояние отображения идентификатора (`ShowRequestId`)**: реактивное отображение блока `<strong>Request ID:</strong>` при наличии непустого идентификатора трассировки.
